# 商品展示数据源

当前默认使用网易严选官网的人民币商品报价、图片和真实评价。列表加载摘要，点击商品后按官网 ID 获取详细信息。网络失败显示重试，不回退到写死的商品。详见 [后端说明](../backend/README.md)。

重新启动 FastAPI 服务并安装最新 APK 后，在商城点击刷新。

以下自有商品管理只在主动设置 `CAMPUS_GOODS_SOURCE=owned` 时用于展示，不是默认模式。

启动 FastAPI 后访问 http://localhost:8000/docs 。

1. 找到“商城管理”的 `POST /api/v1/goods`，点击 Try it out。
2. 填写你自己的商品信息（名称、人民币价格、分类、图片 URL 和说明）。`product_id` 可不填，让服务器生成；销量默认 0。
3. 点击 Execute，保存成功后在 App 商城点击“刷新”。
4. 修改使用 `PUT /api/v1/goods/{product_id}`，删除使用 `DELETE /api/v1/goods/{product_id}`。

商品保存在项目的 `data/shop_products.db`，重启仍保留。可通过环境变量 `CAMPUS_GOODS_DB` 指定另一个数据库路径。商品库不会自动生成或导入测试商品，也不会提交 Git。

模拟器服务地址填写 `http://10.0.2.2:8000`（不附加 `/api/v1`）。空商品库会显示“暂无商品”；加载失败可以点击重试。

这是本地开发服务，管理接口尚未增加账户认证。原有订单、客户端历史购物车、模拟支付保持原有实现；本次只修复商品目录的数据来源。
