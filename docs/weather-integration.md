# 天气接入说明

首页“天气预报”继续使用 WeatherActivity 入口，页面实现位于 demo.weather 包，资源与城市数据使用 weather 前缀隔离。原 Desktop/Android/weather 项目未修改。

- 首次进入默认武汉，支持搜索及选择城市，记住最后选择。
- 展示实时天气、空气信息、15 天预报和温度趋势。
- 使用原项目的 sojson 天气接口：http://t.weather.sojson.com/api/weather/city/{城市编码}，无需启动 FastAPI。
- 按城市保存在应用私有 files/weather 目录；请求失败时读取同城市缓存，提示缓存状态，无缓存则显示失败与重试。
- 城市切换与退出页面会取消旧请求，避免过期结果覆盖当前城市。

旧 FastAPI 天气演示接口及 ECharts 资源保留兼容，新原生天气页不使用它们，也不会用示例天气替代真实结果。

本次验证包含解析、缓存、请求失败、城市隔离等单元测试，以及模拟器默认武汉、搜索切换上海和返回交互。当前开发机对天气服务的实时请求遇到连接中断，实时服务可用性尚未验证成功。
