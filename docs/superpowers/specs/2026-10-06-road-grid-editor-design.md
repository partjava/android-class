# 3D 校园可视化路网编辑器设计规范 (Visual Road Grid Editor Spec)

## 1. 概述与目标
为让用户直观、自由地在校园地图上规划与调整道路，避免手动修改繁琐代码坐标，新增**【路网绘制模式】**：
- 支持**两点交点连线**（快速连出直道、主干道、交叉十字路口）；
- 支持**手指/鼠标涂抹滑动画线**（自由弯曲道路、环湖步道、林荫小道）；
- 自动吸附网格节点，一键生成带路缘石、沥青路面、分道线的真实 3D 道路，并支持持久化保存。

---

## 2. 界面与交互架构

### 2.1 入口与视角切换
- 在右侧工具栏新增 **`【画路】`** 按钮（图标/文字）；
- 点击后平滑切换至**正上方俯视正交视角**（全览校园，底图为高清卫星实景底图，方便用户对照实景白线描画）；
- 屏幕上方滑出编辑器工具栏，底部显示操作提示与操作按钮。

### 2.2 编辑工具条 (Editor Toolbar)
1. **模式切换**：
   - `【连线模式】`：点击起点、点击终点，两点之间生成笔直线段；连续点击形成折线。
   - `【涂抹模式】`：在屏幕上按住拖动，顺着手指轨迹连续铺路。
2. **路宽选择**：
   - `主干道 (6m)` / `常规路 (4.5m)` / `步行道 (3m)`
3. **辅助操作**：
   - `【撤销】`：撤销最近绘制的一条路段；
   - `【清空】`：清空当前编辑草稿；
   - `【生成 3D】`：立即在场景中动态生成实体 3D 沥青道路并退出编辑模式；
   - `【导出数据】`：复制生成的 `roads` 数组 JSON，方便永久固化到源码中。

## 3. 技术实现架构

### 3.1 坐标转换与网格吸附
- 画布映射到校园标准坐标系：`1320 x 1260`（对应 3D 世界尺寸 `330 x 315`，比例 1:4）；
- 网格步长：`step = 20`（相当于现实约 5 米一个网格交点）；
- **节点吸附（Snap-to-Grid）**：
  ```javascript
  const snap = (val, step = 20) => Math.round(val / step) * step;
  ```
  点击或划过附近交点时，自动磁吸到最近的网格点，确保道路平直、交叉口精准闭合。

### 3.2 动态 3D 路网重构 (`campus-ground.js`)
- 在 `campus-ground.js` 中暴露 `window.rebuildCampusRoads(newRoads)`：
  1. 清除原有的道路几何体（`roadMeshGroup`）；
  2. 根据新的线段数组重新实例化道路多边形、路缘石及分道线；
  3. 支持保存至 `localStorage.getItem('custom_campus_roads')`，应用启动时优先载入用户自定义路网。
