# 网易严选商品列表与详情分开加载

## 目标与已确认事实

用户只需要展示真实商品，不需要真实购买。列表先展示一张图片和商品简介，打开商品后再加载详细内容，并支持刷新和更多图片。

目前已有稳定的 `yanxuan-官网商品ID`；详情接口只是查找搜索结果缓存，尚未请求官网详情页。搜索接口未提供评价正文。已抽查官网商品 4215320 的公开详情页，其中包含商品详情图片、参数、评价总数和好评率。评价正文接口尚待验证，不能保证所有商品均可获取。

## 方案比较

1. 列表一次加载所有商品详情：打开详情快，但分类加载会增加许多上游请求，耗时与失败率较高。
2. 列表加载摘要、点击后加载详情（推荐）：列表负担较小，详情先显示摘要再补充真实内容。
3. 直接打开官网网页：接入简单，但不能保持当前 App 商品详情展示方式。

## 推荐方案

- 保留官网商品 ID，每次刷新不生成新 ID，购物车和详情均沿用同一身份。
- 商品列表返回 ID、名称、价格、分类、一张封面、简短介绍、来源和币种；不提前逐个获取详情。
- 点击商品后立即展示已有摘要，异步按 ID 请求真实详情。详情接口可以独立解析有效官网 ID，不依赖该商品仍在当前列表缓存里。
- 详情展示官网实际提供的商品轮播图片、介绍图片和参数；图片去重、按需加载，不复制封面凑数量。
- 分开显示评价总数、好评率和评价正文。正文接口可用时加载真实评价；失败或缺失时明确显示“评价暂未获取”，不把获取失败当作零评价，不生成虚构评论。
- 详情提供刷新和失败重试；失败时保留已显示内容。顶部返回按钮和导航继续固定，页面滚动后仍可操作。
- 后端详情短时缓存，手动刷新可重新请求；页面关闭后忽略迟到的请求结果，避免重复刷新绑定轮播监听器。

## 验证标准

- 列表加载不逐个请求官网详情，稳定 ID 不随刷新改变。
- 点击后出现加载状态，成功补充图片和详情，失败可重试且摘要不消失。
- 评价计数与正文明确区分；未知字段和接口失败不使用编造数据。
- 检查多张图片、缓存与强制刷新、无效 ID、上游失败及退出页面后的回调。
- 运行相关后端测试、Android 构建与设备测试；实际抽查多类商品。提速效果以验证结果为准。
