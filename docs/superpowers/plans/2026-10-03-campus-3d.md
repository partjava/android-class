# Additive campus 3D implementation

Goal: Add a 3D button below existing zoom/reset controls without changing photo mode.
Architecture: Dedicated Java Activity loads bundled Three.js, campus data and scene scripts. Local assets only; no network navigation or JavaScript native bridge. Existing landmark photos shown in native detail cards.

- Validate floor counts and individual dormitory data with Node.
- Build approximate campus geometry from supplied overhead and aerial references, with courtyards, roof shapes, lake, track and roads.
- Implement orbit, zoom, pan, top view, filtering, search and raycast selection.
- Add Activity and fourth control button; register in manifest.
- Build APK and verify on available emulator, including opening from original guide.

Scope: Aboveground exterior sand-table; dimensions estimated; no entrances or indoor navigation. Original landmarks and photo view preserved.
