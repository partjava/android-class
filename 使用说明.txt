晴川校园应用 — 使用说明
更新日期：2026-10-07

一、直接下载安装
APK：https://github.com/partjava/android-class/releases/download/campus-preview-2026-10-07-r2/qingchuan-campus-2026-10-07-r2.apk
发布说明和 SHA-256：https://github.com/partjava/android-class/releases/tag/campus-preview-2026-10-07-r2
适用于 Android 10 及以上，安装包约 20.6 MB。下载 APK 后打开，按系统提示允许本次安装。
这是 debug 测试签名体验包，包含最新地图功能；功能源码已推送，R2 Release 的源码对应提交 268261c。
签名相同通常能覆盖安装并保留本地数据。签名不同时无法直接覆盖，卸载或清除数据会丢失设备上的个人内容和地图配置。
APK 校验（Windows PowerShell）：
Get-FileHash -Algorithm SHA256 .\qingchuan-campus-2026-10-07-r2.apk
将输出与 Release 的 SHA256SUMS.txt 比较。

二、地图快速操作
单指平移，双指以手指中心缩放，松开一根手指后可继续拖动。
点“俯视”进入顶视；顶部可隐藏/显示建筑名称，点建筑查看详情，× 关闭详情卡。
右侧工具轨可上下滑动；选择“路线”，设置起终点，再点“显示路线”。实线为路网路线，虚线为地点连接段。
路线是离线示意路网计算，不包含 GPS 实时定位、经核验入口或室内导航。
“画路”支持两点/连续绘制及擦除；绿色光圈表示吸附已有端点或路段，双指操作优先缩放。
道路编辑支持 100 步撤销/重做、恢复默认道路和连通检查；检查只标记问题，不自动改路。
“移楼”可调整位置和角度并复位；读数和建筑导出相对当前默认，未再调整时为 0。
默认路网有 212 段道路，正大门默认旋转 -75°。设备自定义布局优先加载，覆盖安装不等于恢复默认。
在“默认布局 / 自定义布局 / 默认已更新”入口查看状态；切换最新默认前自动本地备份，可恢复切换前布局。

三、校园资讯服务
无需新闻服务也能浏览本地内容和三维场景。抓取官网资讯时，先在电脑安装 Python 3.8+，双击“启动校园新闻服务.bat”。
启动器检查并安装缺少的依赖，随后启动 Flask；首次安装依赖需要联网，保持终端打开，Ctrl+C 停止。
在 App“我的”右上角网络图标设置地址，测试连接后点击保存。
模拟器使用 http://10.0.2.2:5000；真机使用电脑的局域网 IP，例如 http://192.168.1.8:5000。
手机和电脑须网络互通，防火墙允许 5000 端口。测试连接成功不代表学校官网一定能抓取；服务更新后需重启。

四、下载源码与本地构建
在终端执行：
git clone https://github.com/partjava/android-class.git
cd android-class
用 Android Studio 打开并配置本机 Android SDK，同步 Gradle，运行 app。
项目使用 Java 8、compileSdk 32、minSdk 29。依赖尚未缓存时，同步需要联网。
local.properties 不进入版本控制，每台电脑按本机 SDK 路径配置。
Android Studio 通常会生成；命令行构建可在项目根目录手动创建，例如：
sdk.dir=C:/Users/你的用户名/AppData/Local/Android/Sdk
推荐使用正斜杠，避免 properties 中反斜杠转义错误。不要提交本机 SDK 路径。
构建和单元测试（Windows PowerShell）：
.\gradlew.bat testDebugUnitTest assembleDebug
输出 APK：app/build/outputs/apk/debug/app-debug.apk
Node.js 地图检查：
Get-ChildItem tests/campus3d/test_*.cjs | ForEach-Object { node $_.FullName; if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE } }
仓库共 17 个地图检查。

五、提交修改
首次提交前使用自己的身份配置当前仓库：
git config user.name "你的名字"
git config user.email "你的邮箱"
改动后先检查和验证，再按需提交明确的文件：
git status
git diff
git add 文件路径
git commit -m "说明具体改动"
git push
不要提交 local.properties、构建缓存或私密配置。APK 从 Release 下载，不存入源码目录。

完整功能及演示范围见“项目功能说明.txt”；截图、服务启动故障排查和发布入口见 README.md。
