晴川校园应用 — 项目功能说明
更新日期：2026-10-07
适用版本：2026-10-07 地图体验 APK R2 与仓库 main；功能源码已完整推送，R2 源码对应提交 268261c。

一、项目定位与实现
面向校园资讯、校园导览与生活服务的 Android 课程项目。
原生页面使用 Java + XML，校园三维场景使用 WebView + 本地 Three.js。
校园官网内容由电脑上的 Python Flask 服务抓取，App 通过 HTTP 获取。
主界面包含资讯、影像、发布、导览、生活、我的六个入口。

二、登录与个人资料
提供本地体验、一键登录展示、密码登录及协议入口。
可编辑昵称、头像、简介、性别、生日、所在地等个人资料。
资料、收藏、点赞、作品和设置在设备本地保存；覆盖安装通常保留数据。
第三方登录、账号验证不等同于已经接入真实平台授权。

三、首页资讯
支持标题/内容搜索、横向频道切换、频道增删与本地保存。
校园要闻、通知公告、教育教学、媒体关注、学校荣誉支持官网分页抓取。
学校概况、机构设置、人才培养、师资队伍、教学科研、招生就业等栏目可通过服务展示官网内容。
推荐流包含本地示例资讯和个人发布内容；可选天行新闻接口需要单独配置密钥。
支持文字、单图、三图及大图卡片，文章详情支持正文与多段图文内容。
校园快捷区提供导览与 3D 校园入口，可以向上折叠、再次展开并记住状态。

四、文章互动与内容记录
文章支持点赞、取消点赞、收藏、取消收藏、评论与分享。
阅读历史、收藏和文章点赞快照本地持久化。
“我的”收藏与赞过包含文章和相应视频，标签显示数量。
旧文章点赞在阅读历史或收藏快照仍存在时可恢复；重复标题记录去重。
从收藏/赞过再次打开文章保留正文、网络配图、图文流及原文链接。
“获赞”表示别人给个人内容的点赞，不能当作自己点过赞的数量。
部分评论、粉丝和社交统计仍为课程演示数据。

五、校园导览与三维场景
保留航拍实景、分类筛选、快捷卡片和地标详情。
三维模式支持名称搜索、建筑高亮、分类筛选及隐藏/显示名称。详情卡片的关闭按钮只关闭卡片。
单指默认平移，双指围绕手指中心缩放；松开一根手指后可继续拖动，避免误点建筑。
可切换平移/旋转；俯视按钮高亮，俯视状态下旋转保持顶视角度。
右侧采用毛玻璃工具轨：固定缩放按钮，滑动区展示沙盘/实景、俯视、路线、巡航、复位、画路、移楼及布局状态等操作，记住滚动位置。
画路、移楼使用可收起的底部面板，互相切换时退出前一个编辑器，退出编辑恢复之前底图。
教学楼1—4分别建模，保留各自轮廓、庭院及连接部分，均5层。
宿舍1—10分别按标注轮廓建模，均6层；小宿舍3层。
实验楼1—2、综合楼1—2均5层；美术馆及计算机实验室未确认楼层，显示估计提示。
图书馆地上4层、地下1层；地下层作为资料标注，不提供室内模型。
食堂、体育馆3层；超市与小剧场共用两层建筑（1楼超市，2楼小剧场）。
重建情缘湖、道路、草坪、操场、停车场及体育馆周边铺地。
包含北侧/西侧篮球场、羽毛球场、排球场、小吃街和驾校区域。
区域支持搜索和点击信息；小吃街有示意摊位和棚顶，驾校有示意训练标线、锥桶和车辆。
建筑尺寸、屋顶细节、设施数量和位置依据截图近似重建，不是测绘成果。
提供离线道路路线规划：选择起点/终点，支持交换地点、显示和清除路线；实线沿路网行走，虚线为地点连接段。
路线使用当前道路及建筑位置，处理交叉点和符合条件的小间隙，并检查建筑/湖面障碍；编辑完成后刷新路线。
情缘湖的路线终点放在湖岸；没有道路、起终点相同或道路无法连通时显示对应原因。
不提供 GPS 实时定位、经实地核验的建筑入口、室内导航、逐层模型或真实步行距离/时间。

五（一）、道路编辑与连通检查
默认路网为用户确认的 212 段道路，包含新增闭合环路。路口使用圆顺接头，路沿不横穿路面，中线在交汇处留白。
画路支持两点连线、连续绘制、擦除与移动视野；靠近已有端点或路段自动吸附，绿色光圈表示已吸附。
吸附会连接到附近道路，不会把远处断路自动补齐；擦除模式不吸附，双指操作暂停编辑并撤回未完成的误画/误擦。
道路支持最多 100 步撤销/重做，新编辑清除重做历史；恢复默认道路可撤销，清空道路前提示确认。
检查连通会显示路网分区数量，标出端点（橙色圈）、近距离间隙（橙红线）和主路网外的路段（红线）。
端点可能是正常入口；连通检查不自动修改路网，也不能代替规划时的建筑障碍检查。
道路导出为宽度和坐标点列表，坐标不会因设置默认而归零。

五（二）、建筑默认布局与本地保存
正大门已加入场景，用户默认旋转为 -75°；其余对象沿用用户校准位置。湖面和湖岸线一起移动。
移楼支持移动、旋转、撤销/重做、当前对象复位和全部复位；复位恢复用户确认的默认位置。
建筑读数和导出相对当前项目默认布局计算，未再调整时 dx、dz、rot 为 0；内部保存保持旧格式兼容。
设备保存的自定义布局优先加载，覆盖安装不会自动覆盖它；工具栏显示默认/自定义布局及已知的默认版本更新状态。
旧布局无版本记录时只提示与默认不同，不将其误判为已知的新版本更新。
布局管理支持切换最新默认道路和建筑配置，切换前保存一份本地备份，可恢复切换前布局。
备份在同一设备保存，不是跨设备云备份；清除应用数据或卸载通常会丢失个人数据和自定义布局。
三维基础场景随 APK 打包，可离线浏览。

六、影像与创作
提供推荐全屏视频流、视频网格、搜索、详情播放及相关内容入口。
本地短片可离线播放；支持播放/暂停、点赞、收藏、分享及评论入口。
发布支持校园动态、文章、视频和问答等课程演示流程。
个人作品可在“我的”查看、筛选和删除，发布内容可加入首页推荐。
未接入公网内容分发平台，不代表真实社交媒体发布。

七、生活服务与购物演示
支持商品列表、分类/搜索、商品详情、购物车、数量调整及结算流程。
支持本地订单、订单详情、取消/删除、物流展示和客服入口。
提供优惠券、签到、会员权益等本地与 H5 演示页面。
没有真实支付、发货或交易后台；余额、物流和权益是课程演示逻辑。

八、我的、消息与设置
“我的”提供作品、收藏、赞过、历史、资料、资产和功能快捷入口。
消息列表支持未读展示、本地对话历史和文本发送，回复为本地模拟。
设置包含个人偏好、隐私说明、帮助、关于及退出登录。
部分选项是展示或本地设置，不代表已实现系统级功能。

九、校园网络配置
入口：“我的”右上角网络图标，在好友图标左侧。
模拟器模式：http://10.0.2.2:5000，连接模拟器所在电脑。
真机/自定义模式：填写运行爬虫电脑的局域网完整地址，如 http://192.168.1.8:5000。
模拟器和真机模式都可测试连接；测试草稿不自动保存，点击保存后持续生效。
新闻、官网子页面与图片代理使用当前服务地址。
手机和电脑需在可互通的局域网，电脑运行爬虫并允许对应端口。
检测接口 /api/health 检查校园服务身份与连接，不证明学校官网一定能抓取。
更新服务代码后需重启 Python。离开局域网使用需要自行部署可访问的服务器。

十、一键启动校园新闻服务
双击项目根目录“启动校园新闻服务.bat”，终端逐步显示进度。
1. 自动寻找并验证 Python 3.8+，从 PATH、py launcher、注册表及常见安装目录发现解释器。
2. 检查爬虫文件及 flask、requests、beautifulsoup4、urllib3。
3. 缺少依赖时检查/初始化 pip，默认使用清华镜像安装，失败后回退官方源；显示源地址和下载输出，已有包不重复下载。
4. 验证依赖能正常导入。
5. 使用找到的解释器启动 Flask，窗口持续显示服务日志。
未找到 Python 时会提示安装；启动器不自动下载安装 Python 本身。
依赖下载需要联网；下载失败、端口占用等错误会保留在终端供检查。
运行时保持终端打开，Ctrl+C 停止；不需要反复启动多个服务。

十一、数据与功能边界
App 个人内容主要存储于本地，校园资讯依赖官网及 Python 服务可用。
官网结构变化、网络限制或代理环境可能导致抓取失败。
本版本未实现 AI 智能体、自动学习计划、课表同步、真实活动报名等后续设想。
不会把规划中的功能当作已完成功能。
更多启动步骤和真实运行截图见 README.md；下载与安装步骤见 使用说明.txt。
